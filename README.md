# MythicFPS

Minecraft Forge 1.16.5 optimization mod focused on FPS and RAM improvements.

## Features
- FPS optimization
- Tick optimization
- Entity optimization
- Lightweight structure
- Forge 1.16.5 compatible

## Build
```bash
gradlew build
```

Output:
```plaintext
build/libs/mythicfps-1.0.jar
```
